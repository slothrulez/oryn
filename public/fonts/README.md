# Subtitle font

`subtitle.ttf` is **Noto Sans Regular** (Google / The Noto Project Authors, SIL OFL 1.1, see `OFL.txt`).

`resolveSubtitleFontFile()` in `src/lib/video-composer/composer.ts` prefers this bundled font so
subtitles, badges and overlays render identically on every platform (system fonts vary by OS).

Source: https://github.com/notofonts/notofonts.github.io/raw/main/fonts/NotoSans/hinted/ttf/NotoSans-Regular.ttf
